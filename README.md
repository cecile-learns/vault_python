# Vault Python — Fiches de référence

Ce dépôt rassemble mes fiches pratiques sur Python et ses principales bibliothèques utilisées en Data Science, constituées au fil de ma formation.

Elles sont organisées par thèmes et par usages pour retrouver rapidement une commande, une méthode ou un exemple de code.

## Qu'est-ce qu'Obsidian ?

[Obsidian](https://obsidian.md/) est une application gratuite pour un usage personnel, qui permet de créer et d'organiser des notes au format Markdown (`.md`).

Les notes sont conservées localement dans un dossier appelé *Vault* (coffre de notes). Obsidian permet notamment de naviguer entre les fiches à l'aide de liens internes `[[Nom de la note]]` et de construire progressivement une base de connaissances interconnectée.

**Télécharger Obsidian :** https://obsidian.md/download

## Récupérer les fiches

1. Cliquer sur **Code → Download ZIP** sur GitHub, ou cloner le dépôt.
2. Extraire le dossier téléchargé.
3. Dans Obsidian, choisir **Ouvrir un dossier comme coffre** et sélectionner le dossier contenant les fiches.

Les fichiers `.md` peuvent également être consultés avec n'importe quel éditeur Markdown, sans installer Obsidian.

## Contenu du dépôt

Le dossier `Python/` regroupe les fiches de référence et leurs exemples d'utilisation.

Ce dépôt est évolutif : les fiches peuvent être complétées, corrigées ou réorganisées au fil des apprentissages.
