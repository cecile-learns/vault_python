# Vault Python — Fiches de référence

Ce dépôt rassemble mes fiches pratiques sur Python et ses principales bibliothèques utilisées en Data Science, constituées au fil de ma formation.

Elles sont organisées par thèmes et par usages pour retrouver rapidement une commande, une méthode ou un exemple de code.

## Nouvelle organisation du Vault — Octobre 2026

Le Vault a été réorganisé afin de faciliter la recherche et la réutilisation des connaissances acquises pendant ma formation Data Scientist.

**Pourquoi cette évolution ?**

L'organisation initiale reposait principalement sur les bibliothèques Python (Pandas, NumPy, Scikit-learn, etc.). Avec la progression de la formation, cette structure est devenue moins adaptée à une utilisation transversale des outils.

**Une nouvelle organisation par domaine et par action**

Le dossier `02_VAULT_ACTIONS` propose une architecture centrée sur les besoins pratiques : manipulation des données, preprocessing, visualisation, traitement du texte, modélisation, etc.

L'objectif est de retrouver rapidement les méthodes et commandes correspondant à une tâche, indépendamment de la bibliothèque utilisée.

**Conservation de l'ancienne organisation**

Le Vault initial a été conservé pour préserver l'historique des fiches et permettre la comparaison entre les deux structures.

Cette nouvelle organisation est amenée à évoluer avec l'acquisition de nouvelles compétences durant la formation.



## Qu'est-ce qu'Obsidian ?

[Obsidian](https://obsidian.md/) est une application gratuite pour un usage personnel, qui permet de créer et d'organiser des notes au format Markdown (`.md`).

Les notes sont conservées localement dans un dossier appelé *Vault* (coffre de notes). Obsidian permet notamment de naviguer entre les fiches à l'aide de liens internes `[[Nom de la note]]` et de construire progressivement une base de connaissances interconnectée.

**Télécharger Obsidian :** https://obsidian.md/download

## Récupérer les fiches

1. Cliquer sur **Code → Download ZIP** sur GitHub, ou cloner le dépôt.
2. Extraire le dossier téléchargé.
3. Dans Obsidian, choisir **Ouvrir un dossier comme coffre** et sélectionner le dossier contenant les fiches.

Les fichiers `.md` peuvent également être consultés avec n'importe quel éditeur Markdown, sans installer Obsidian.

## Contenu du dépôt

Le dossier `Python/` regroupe les fiches de référence et leurs exemples d'utilisation.

Ce dépôt est évolutif : les fiches peuvent être complétées, corrigées ou réorganisées au fil des apprentissages.

### ⚠️ Avertissement — Fiabilité des contenus

Ce Vault est un **support personnel d'apprentissage**, construit et enrichi progressivement au cours de ma formation en Data Science.

Les fiches sont issues de mes cours, de mes exercices, de recherches complémentaires et d'échanges avec des outils d'intelligence artificielle.

**Malgré un travail de vérification, elles peuvent contenir des erreurs, des approximations ou des informations incomplètes.** Certaines fiches peuvent également évoluer à mesure que ma compréhension des concepts progresse.

Ces contenus ne constituent donc pas une documentation de référence. Je recommande de vérifier les informations et les exemples de code dans les documentations officielles avant toute réutilisation.
