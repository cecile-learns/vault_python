# ylim

> [!info] Bibliothèque
> Matplotlib

## Syntaxe

```python
limites = plt.ylim(minimum, maximum)
```

## Paramètres

`minimum`, `maximum` : bornes de l’axe en unités des données.

## Fonction

Fixe et retourne les limites de l’axe y.

Source : Liora, cours Matplotlib ; ressources personnelles de visualisation.

## Paramètres courants complémentaires

`plt.ylim()` sans argument retourne les limites actuelles. `bottom` et `top` peuvent aussi être fournis séparément, par exemple `plt.ylim(bottom=0)`. Inverser leur ordre inverse l’axe.
