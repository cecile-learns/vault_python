# set_axisbelow

> [!info] Bibliothèque
> Matplotlib

## Syntaxe

```python
ax.set_axisbelow(True)
```

## Paramètres

`ax` : graphique ciblé ; `True` : placer les graduations et la grille sous les tracés.

## Fonction

Évite que la grille recouvre les barres.

Source : Data Visualisation, partie 4.

## Paramètres possibles

| Valeur | Effet |
|---|---|
| `True` | Place graduations et grille sous les autres éléments. |
| `'line'` | Les place au-dessus des aplats, mais sous les lignes et marqueurs. |
| `False` | Les place au-dessus des autres éléments. |
