# show

> [!info] Bibliothèque
> Matplotlib

## Syntaxe

```python
plt.show()
```

## Paramètres

Aucun argument requis dans cette syntaxe.

## Fonction

Affiche les figures ouvertes.

## Vigilances & tips

L’affichage automatique d’un notebook peut rendre cet appel facultatif. Enregistrer avec `savefig` avant un `show` bloquant.

Source : Liora, cours Matplotlib ; ressources personnelles de visualisation.

## Paramètre disponible

`block=True` attend la fermeture des fenêtres avant de poursuivre le programme ; `block=False` rend la main immédiatement. Dans un notebook, ce réglage est rarement nécessaire.
