# Vue d’ensemble — régression

Une cible quantitative connue → régression. Le même estimateur LinearRegression couvre une ou plusieurs variables explicatives.

| Besoin | Méthode |
|---|---|
| Référence linéaire | Régression linéaire |
| Contracter les coefficients sans sélection explicite | Ridge |
| Pénaliser et annuler certains coefficients | Lasso |
| Combiner L1 et L2 | Elastic Net |
| Essayer une relation non linéaire | SVR, KNN ou Random Forest Regressor |

Préparer les données avec les fiches d’Outils transversaux. Les métriques restent dans la famille concernée. Les fiches de méthode détaillent leurs prérequis.
