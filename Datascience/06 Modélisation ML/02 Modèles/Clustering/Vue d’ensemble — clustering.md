# Vue d’ensemble — clustering

Découvrir des groupes sans cible d’apprentissage. Les numéros de groupes ne sont pas des classes connues.

| Besoin | Méthode |
|---|---|
| Nombre de groupes fixé, groupes compacts | K-Means |
| Hiérarchie de regroupements | Classification ascendante hiérarchique |
| Groupes autour de modes de densité | Mean Shift |

Le cours regroupe toutes les observations pour une analyse exploratoire. Pour un usage prédictif ultérieur, distinguer données d’apprentissage et nouvelles observations ; toutes les méthodes n’ont pas predict.

Préparer les données avec les fiches d’Outils transversaux. Les métriques restent dans la famille concernée. Les fiches de méthode détaillent leurs prérequis.
