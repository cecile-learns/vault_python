# Organisation du Vault par actions

Ce Vault est une seconde organisation des notes techniques. Le Vault d'origine reste la source conservée.

La navigation part du besoin : manipuler des données, préparer les données, visualiser, modéliser, automatiser ou présenter les résultats. Une même commande peut apparaître dans plusieurs contextes lorsque son pattern d'utilisation change.

## Branches principales

1. Python général
2A. Manipulation des arrays
2B. Manipulation des tenseurs
3. Manipulation des DataFrames
4. Dataviz
5. Préparation et traitements spécialisés
6. Modélisation ML
7. Deep Learning
8. Automatisation
9. Présentation des résultats

La branche **Préparation et traitements spécialisés** regroupe le préprocessing transversal, les séries temporelles, les images, le texte, ainsi que les graphes et réseaux. La branche **Deep Learning** contient les tenseurs, gradients, pipelines TensorFlow, modèles Keras, entraînement, architectures et interprétation.

Deux formats coexistent :

- **fiche-commande** : pattern, paramètres, exemple et vigilances ;
- **workflow complet** : enchaînement réutilisable de la préparation à l'évaluation lorsque le chemin technique est stable.

La bibliothèque et l'import restent visibles dans chaque fiche, même lorsque le classement est fondé sur l'action.
