# Organisation du Vault par actions

Ce Vault est une seconde organisation des notes techniques. Le Vault d'origine reste la source conservée.

La navigation part du besoin : manipuler des données, préparer un modèle, traiter du texte, visualiser ou modéliser. Une même commande peut apparaître dans plusieurs contextes lorsque son pattern d'utilisation change.

Deux formats coexistent :

- **fiche-commande** : syntaxe, paramètres, exemple et vigilances ;
- **workflow complet** : enchaînement directement réutilisable lorsque le chemin technique est stable.

La bibliothèque et l'import doivent rester visibles dans chaque fiche, même lorsque le classement est fondé sur l'action.
