# torch.concat

## Syntaxe

```python
tensor_assemble = torch.concat([tensor_a, tensor_b], dim=0)
```

## Paramètres

| Paramètre | Rôle |
|---|---|
| liste de tenseurs | objets assemblés |
| `dim` | dimension de concaténation |

## Vigilances & tips

Toutes les autres dimensions doivent être compatibles.
