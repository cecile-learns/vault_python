# Préparer les données temporelles


## Contrôles avant la modélisation

- dates converties en `datetime` ;
- ordre chronologique ;
- une observation par date attendue ;
- fréquence connue et régulière ;
- valeurs manquantes repérées ;
- variable cible numérique.
