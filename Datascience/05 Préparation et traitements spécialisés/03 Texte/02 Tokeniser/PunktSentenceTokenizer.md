# `PunktSentenceTokenizer`

## Syntaxe

```python
from nltk.tokenize import PunktSentenceTokenizer

tokeniseur = PunktSentenceTokenizer()
phrases = tokeniseur.tokenize(texte)
```

## Fonction

Découpe un texte en phrases.

Documentation : [tokeniseurs NLTK](https://www.nltk.org/api/nltk.tokenize.html)
