# `word_tokenize`

## Syntaxe

```python
from nltk.tokenize import word_tokenize

mots = word_tokenize(texte, language="french")
```

## Paramètres

- `texte` : chaîne à découper ;
- `language` : modèle linguistique utilisé.

## Vigilances & tips

Le modèle Punkt requis doit être disponible dans les ressources NLTK.

Documentation : [`word_tokenize`](https://www.nltk.org/api/nltk.tokenize.word_tokenize.html)
