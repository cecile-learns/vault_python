# append

## Syntaxe

```python
liste.append(valeur)
```

## Fonction

Ajoute un élément à la fin de la liste.

## Vigilances & tips

Modifie la liste sur place et ne retourne pas la liste.

```python
#ajouter des éléments à une liste
colors=[]
colors.append('red')
colors.append('green')
colors.append('blue')
print(colors)
```
