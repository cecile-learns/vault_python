# man

## Pour faire quoi ?

Lire le manuel d’une commande installée sur le système.

## Arguments

Le nom de la commande est l’argument : `man ls`.

## Options ou éléments utiles

Dans le manuel : `/mot` recherche ; `n` va au résultat suivant ; `q` quitte. `man -k mot` cherche des manuels par mot-clé.

## Exemple du cours

```bash
man chmod
```

## Vigilances et repères

Le manuel décrit la version présente sur la machine. Il est particulièrement utile avant une option inconnue ou une commande qui modifie des fichiers.
