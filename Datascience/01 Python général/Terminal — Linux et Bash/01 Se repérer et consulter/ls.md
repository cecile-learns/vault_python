# ls

## Pour faire quoi ?

Lister le contenu d’un répertoire.

## Arguments

Sans argument, liste le dossier courant. Donner un chemin liste ce dossier : `ls /chemin`.

## Options ou éléments utiles

`-l` : vue détaillée ; `-a` : inclut les éléments cachés ; `-h` : tailles lisibles, souvent avec `-l` ; `-R` : parcours récursif.

## Exemple du cours

```bash
ls -la
```

## Vigilances et repères

Les fichiers commençant par un point sont cachés. `ls` n’altère rien : c’est une commande de consultation.
