# pwd

## Pour faire quoi ?

Afficher le répertoire dans lequel le terminal travaille actuellement.

## Arguments

Aucun argument dans l’usage courant.

## Options ou éléments utiles

`pwd` signifie *print working directory*.

## Exemple du cours

```bash
pwd
```

## Vigilances et repères

C’est le premier réflexe avant une action sur un fichier : il évite de travailler dans le mauvais dossier.
