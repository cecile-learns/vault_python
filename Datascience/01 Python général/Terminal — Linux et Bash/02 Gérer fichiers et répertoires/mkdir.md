# mkdir

## Pour faire quoi ?

Créer un ou plusieurs répertoires.

## Arguments

Un ou plusieurs noms ou chemins de dossiers.

## Options ou éléments utiles

`-p` : crée aussi les dossiers parents manquants ; `-v` : affiche les dossiers créés.

## Exemple du cours

```bash
mkdir -p projet/donnees/brutes
```

## Vigilances et repères

Sans `-p`, la commande échoue si un dossier parent n’existe pas.
