# tuple()

## Syntaxe

```python
coordonnees = tuple(valeurs_coordonnees)
```

## Fonction

Convertit un itérable en tuple immuable.

peut faire une somme sur les éléments de tuple somme=sum(numbers)

```python
# Définir un tuple
my_tuple = ("apple", "banana", "cherry", "date")

# Trouver l'indice de l'élément "cherry"
index = my_tuple.index("cherry")

print("L'indice de 'cherry' est :", index)
```
