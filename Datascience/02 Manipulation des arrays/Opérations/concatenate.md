# concatenate

## Syntaxe

```python
tableau = np.concatenate([tableau1, tableau2], axis=0)
```

## Paramètres

`axis=0` empile les lignes ; `axis=1` juxtapose les colonnes.

## Fonction

Concatène des arrays sur un axe.

## Vigilances & tips

Les dimensions autres que l’axe de concaténation doivent correspondre.
