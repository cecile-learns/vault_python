# Vue d’ensemble — classification

Une cible catégorielle connue → classification. Une cible quantitative → régression. Des groupes à découvrir sans cible → clustering.

| Besoin | Première famille à examiner |
|---|---|
| Référence linéaire et probabilités | Régression logistique |
| Frontière à marge, noyau non linéaire | SVM |
| Décider par proximité | KNN |
| Règles lisibles | Arbres de décision |
| Ensemble d’arbres | Random Forest, Bagging & Boosting |
| Combiner différentes familles | Voting et Stacking |

Ces repères orientent les essais ; ils ne désignent pas un gagnant universel.

Préparer les données avec les fiches d’Outils transversaux. Les métriques restent dans la famille concernée. Les fiches de méthode détaillent leurs prérequis.
