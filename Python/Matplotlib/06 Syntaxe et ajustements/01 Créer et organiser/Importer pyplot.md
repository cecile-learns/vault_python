# Importer pyplot

## Syntaxe

```python
import matplotlib.pyplot as plt
```

## Paramètres

`plt` : alias utilisé pour le module de tracé `matplotlib.pyplot`.

## Fonction

Rend les fonctions pyplot accessibles.

## Vigilances & tips

Dans Jupyter, `%matplotlib inline` active le rendu intégré ; cette commande spéciale ne se met pas dans un fichier Python classique. Le point-virgule final masque les retours textuels dans le notebook.
