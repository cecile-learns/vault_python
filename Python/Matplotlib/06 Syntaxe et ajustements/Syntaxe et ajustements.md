# Syntaxe et ajustements

Préambule des micro-fiches : `import matplotlib.pyplot as plt`. Les variables de données doivent déjà exister.

`fig` désigne la figure entière ; `ax` un graphique dans cette figure. `plt.…` agit sur le graphique courant. Pour une variante `ax.…`, créer ou récupérer cet Axes au préalable.

Les noms de variables des syntaxes sont à remplacer ; les scripts complets sont accessibles depuis les entrées par situation.
