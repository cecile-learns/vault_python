# import seaborn

## Pour faire quoi ?

Rendre les fonctions Seaborn accessibles avec l’alias conventionnel `sns`.

## Syntaxe réutilisable

```python
import seaborn as sns
```

## Paramètres courants

| Paramètre | Description |
|---|---|
| `sns` | Alias conventionnel utilisé dans les notebooks et la documentation. |

## Fonction

L’import charge la bibliothèque ; il ne trace rien et ne charge aucune donnée.

## Vigilances & tips

- Seaborn s’appuie sur Matplotlib ; importer aussi `matplotlib.pyplot as plt` pour régler ou afficher la figure.
- Les données sont généralement fournies sous forme de DataFrame Pandas.
