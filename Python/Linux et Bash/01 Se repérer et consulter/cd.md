# cd

## Pour faire quoi ?

Changer le répertoire courant du terminal.

## Arguments

Le chemin cible est l’argument : `cd dossier`, `cd /chemin/complet`.

## Options ou éléments utiles

`cd ..` remonte d’un niveau ; `cd ~` revient au dossier personnel ; `cd -` revient au dossier précédent.

## Exemple du cours

```bash
cd Documents
```

## Vigilances et repères

Un chemin relatif part du dossier affiché par `pwd`. Un chemin absolu commence par `/`.
