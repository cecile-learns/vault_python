# mv

## Pour faire quoi ?

Déplacer un fichier ou un dossier, ou le renommer.

## Arguments

Premier argument : source ; dernier argument : destination ou nouveau nom.

## Options ou éléments utiles

`-i` : demande confirmation avant écrasement ; `-n` : ne remplace jamais un fichier existant ; `-v` : affiche l’action.

## Exemple du cours

```bash
mv brouillon.txt rapport.txt


naude@pccecile:~$ mv formation-datascientest formation #à modifier le nom du dossier
```

## Vigilances et repères

Un renommage est un déplacement dans le même dossier. Vérifier si la destination existe avant de remplacer un fichier.
