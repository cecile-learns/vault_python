# nano et vim

## Pour faire quoi ?

Ouvrir et modifier un fichier texte dans le terminal.

## Arguments

Le chemin du fichier est l’argument : `nano fichier.txt` ou `vim fichier.txt`.

## Options ou éléments utiles

Nano : `Ctrl+O` enregistre, `Ctrl+X` quitte. Vim : `i` insère, `Esc` sort du mode insertion, `:w` enregistre, `:q` quitte, `:wq` enregistre et quitte.

## Exemple du cours

```bash
nano script.sh
```

## Vigilances et repères

Ces éditeurs peuvent créer un fichier s’il n’existe pas. Dans Vim, il faut distinguer le mode normal et le mode insertion.
