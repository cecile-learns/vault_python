# rm

## Pour faire quoi ?

Supprimer des fichiers, ou des répertoires avec leur contenu.

## Arguments

Un ou plusieurs chemins ciblés.

## Options ou éléments utiles

`-i` : demande confirmation ; `-r` ou `-R` : supprime récursivement un dossier ; `-f` : force sans demander.

## Exemple du cours

```bash
rm fichier_temp.txt

```
rmdir /home/ubuntu/linux_bash
```
```

## Vigilances et repères

La suppression est définitive dans le terminal : vérifier avec `pwd` et `ls` avant. Éviter `rm -rf` sauf cible parfaitement connue.
