# Vue d’ensemble — réduction de dimension

Réduire le nombre de colonnes par sélection de variables ou construction de nouvelles coordonnées.

| Approche | Méthodes du cours |
|---|---|
| Garder des variables originales | Filtres, RFE/RFECV, SelectFromModel |
| Construire des axes linéaires sans cible | PCA |
| Construire des axes avec les classes | LDA |
| Représenter une géométrie non linéaire | Isomap, LLE, t-SNE |

La sélection supervisée et LDA utilisent y ; elles ne sont donc pas des méthodes non supervisées. UMAP est aussi illustré dans la ressource, mais appartient au package umap-learn, pas à sklearn.

Préparer les données avec les fiches d’Outils transversaux. Les métriques restent dans la famille concernée. Les fiches de méthode détaillent leurs prérequis.
